# Budget Manager

현재 자산과 매달의 수입·지출·저축·투자를 정리하고, 앞으로의 순자산을 그려 보는 한국어 PWA입니다.

## 사용하기

1. **나의 자산**에서 현금, 예·적금, 투자 평가액, 부채를 입력합니다. 입력 단위는 만 원이며 0.0001만 원(1원)까지 입력할 수 있습니다.
2. **월 예산**에서 반복 수입, 생활 지출, 저축, 투자 금액을 입력합니다.
3. **자산 예측**에서 1·3·5·10년 전망과 생활비·투자액·수익률 시나리오를 비교합니다.
4. 실제 잔액을 수정하고 **기록과 백업 → 이번 달 기록**으로 실제 월별 잔액을 남깁니다. 같은 달 기록은 확인 후 갱신합니다.
5. 정기적으로 **백업 내보내기**를 사용해 파일을 기기 밖에도 보관합니다. 백업 불러오기는 확인 후 현재 기기의 전체 데이터를 교체합니다.

## 저장과 설치

- 재정 데이터는 같은 기기·브라우저·출처(origin)의 IndexedDB에 저장합니다. 서버 전송, 계정 로그인, 기기 간 자동 동기화는 없습니다.
- 기존 기록·백업과의 호환성을 위해 내부 DB·백업 식별자 `moa-budget-manager`는 유지합니다. 같은 GitHub Pages 호스트의 다른 프로젝트는 출처를 공유하므로 신뢰할 수 있는 코드만 그 호스트에 배포해야 합니다.
- DB 트랜잭션이 완료된 뒤 저장 성공을 표시합니다. 다른 창의 변경을 오래된 상태로 덮어쓰려 하면 차단하고 새로고침을 안내합니다.
- 홈 화면 설치 후 앱 리소스의 오프라인 준비가 완료되면 입력·조회·예측을 오프라인에서 사용합니다. 최초 방문, 설치와 업데이트에는 네트워크가 필요합니다.
- 브라우저 보존 요청은 승인 여부에 따라 동작하며 사용자의 데이터 삭제를 막지 않습니다. 기기 분실, 사이트 데이터 삭제, 브라우저 변경, 도메인 변경에 대비해 백업해야 합니다.
- JSON 백업은 암호화되지 않은 파일이며 실제 금액을 포함합니다. 개인 보관 장소에 저장하세요. 백업 파일은 Git 저장소에 넣지 마세요.
- 업데이트는 안내 버튼으로 적용합니다. 입력 폼을 열었거나 저장 중이면 업데이트 버튼이 비활성화됩니다. 앱 리소스 캐시 갱신은 IndexedDB 기록을 삭제하지 않습니다.

## 계산 기준

- 순자산 = 현금 + 예·적금 + 투자 평가액 − 부채.
- 남는 월 현금 = 수입 − 생활 지출 − 저축 납입 − 투자 납입.
- 저축과 투자는 현금에서 자산으로 옮기는 내부 이동입니다. 순자산에서 중복 차감하지 않습니다.
- 현재 잔액을 기준으로 **다음 달 말부터** 매달 계산합니다. 수익률은 `(1 + 연수익률 / 100)^(1/12) - 1`로 환산하고, 월말 납입을 더합니다.
- 기본 수익률은 0%입니다.
- 예정 수입·지출은 지정한 미래 월의 현금에 한 번 반영합니다. 이미 지난 항목을 현재 잔액에서 다시 차감하지 않습니다.
- 부채 잔액은 고정합니다. 세금·수수료·물가·대출 이자 및 원금 상환은 자동 계산하지 않습니다. 현금 부족은 음수로 표시하며 자동 차입이나 투자 매각을 가정하지 않습니다.
- 시나리오 변경은 비교용입니다. 기본 가정은 ‘가정 저장’으로, 월 배분은 월 예산 화면에서 수정합니다.

## 개발

Node.js 24 사용을 권장합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

로컬 주소는 `http://127.0.0.1:5173/budget_manager/`입니다. 프로덕션 빌드 미리보기는 포트 4173을 사용합니다. 개발 모드에서는 서비스 워커를 등록하지 않습니다.

```sh
npx playwright install chromium
npm run test:e2e
```

금융 계산·백업 검증·저장 충돌 단위 테스트와 데스크톱/모바일 Chromium의 입력→재실행→백업/복원→오프라인 통합 테스트를 제공합니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다. `main`에 푸시하면 테스트와 빌드를 통과한 결과물을 배포합니다. 필요한 경우 Actions에서 `Verify and deploy to GitHub Pages`를 수동 실행할 수 있습니다.

배포 대상 주소: `https://moonflute.github.io/budget_manager/`

`vite.config.ts`의 base, manifest id/start_url/scope 및 서비스 워커 경로는 `/budget_manager/` 기준입니다. 저장소 이름이나 도메인을 바꾸기 전 데이터를 백업하고 이 경로들을 함께 수정하세요.

## 기술

React · TypeScript · Vite · IndexedDB · vite-plugin-pwa · Lucide · Vitest · Playwright.

서버·외부 API·분석 스크립트·외부 폰트 없이 동작합니다. 빌드 산출물에는 실제 사용자 데이터가 포함되지 않습니다.
